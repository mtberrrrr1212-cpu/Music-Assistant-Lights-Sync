# Music Assistant Lights Sync

A Home Assistant App repository for synchronizing smart lights with Music Assistant digital audio.

## 🚀 Getting Started

This repository is a valid **Home Assistant App Repository**. 

### 1. Installation
To install the visualizer in Home Assistant:
1. Copy the URL of this GitHub repository.
2. In Home Assistant, go to **Settings** -> **Add-ons** -> **Add-on Store**.
3. Click the three dots (top right) -> **Repositories**.
4. Paste this URL and click **Add**.
5. Find **Music Assistant Visualizer** in the store and install it.

### 2. Usage
Detailed instructions for replacing the standard Music Assistant server and configuring the pulse effects are available in the [Music Assistant Visualizer README](./music_assistant_visualizer/README.md).

## 🛠️ Components
- **React Simulator**: An interactive web dashboard to test the audio analysis and Home Assistant connection in your browser.
- **Home Assistant App**: The production-grade Add-on that taps into the Music Assistant server.
